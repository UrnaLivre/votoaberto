# Proposta de primeira release Web — Voto Aberto 0.5.0

**Rascunho para revisão. Não publicado.** Tag proposta: `v0.5.0`, preservando
a versão `0.5.0+3` do aplicativo. Confirmar a política do mantenedor antes de tag.
Esta entrega empacota a experiência geográfica existente; não é uma nova geração
do produto e não acrescenta dados eleitorais.

- Preparação Flutter Web para Workers Static Assets, com recursos locais,
  build de versão fixa, testes e publicação controlada a partir da main.
- Metadados de Voto Aberto — Urna Livre e link institucional acessível na Web.
- Verificação automática de integridade, limites de assets, HTTP e navegação.
- Cache por revalidação e retirada do service worker legado.
- Navegação e funcionalidades Android preservadas.

Publicação depende de aprovação do código e dos dados. O conjunto local atual
declara 2026 e continua `not_ready`, com pendências de hashes de origem e revisão
de redistribuição. Não apresentar a compilação local como release pública aprovada.

Na publicação autorizada, registrar nesta nota: commit aprovado, ID/hash do
dataset, versão de deploy Cloudflare, resultados do CI e URL confirmada.
Manter a atribuição ao TSE e as limitações de interpretação no aplicativo.
