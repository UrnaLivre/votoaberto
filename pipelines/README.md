# Pipelines de dados

`tse_importer` é o Data Engine Python compartilhado pelo
[VotoAberto Auditor](../apps/votoaberto_auditor/README.md).

Instale na raiz com `python -m pip install '.[dev]'`. Inventário, hashes,
streams, checkpoints, reconciliação e SQLite estão implementados. O aplicativo
Flutter continua demonstrativo. Não versionar fontes ou bancos eleitorais reais.
